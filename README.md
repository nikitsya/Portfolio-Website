# Nikita Smiichyk — Portfolio

My personal portfolio, showcasing backend, API and IoT projects, with screenshots, live demos, my tech stack and CV.

[Visit the portfolio](https://nikitsya.com)

Built with HTML, CSS and vanilla JavaScript.

To preview locally, run `python3 -m http.server 8000` from the project folder and
open [localhost:8000](http://localhost:8000).

Pages have their own folders. Shared styles, scripts and images live in `assets/`, navigation in `partials/`, and the
book section in `books/`. The old `book/` addresses redirect to `books/`. Previous screenshots are kept in
`docs/screenshots/`.

Icons are organised into `assets/icons/brands/`, `assets/icons/ui/` and `assets/icons/licences/`.
Their original sources are recorded in `assets/icons/sources.json`.

Screenshots in `assets/images/projects/` are grouped by project: `billing-platform/`, `unistow/`, `tempsafe/` and `mexico-guide/`.

Run `python3 scripts/check_site.py` to check local links and assets.
